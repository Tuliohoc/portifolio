About me

About Me

I'm a QA Engineer with hands-on experience in manual testing, test automation, API validation and software quality.

My day-to-day work involves functional and regression testing, end-to-end automation, API validation, database analysis and investigation of issues across different environments.

I work with tools such as Cypress, Playwright, Postman, Insomnia, PostgreSQL, MongoDB, Datadog and k6, combining automated testing with technical investigation to understand not only whether something fails, but also how and why it fails.

Before moving into QA, I worked in technical support across N1 and N2 levels and later as a Squad Lead. This experience strengthened my troubleshooting, incident investigation, communication and problem-solving skills — especially when dealing with real production issues and customer impact.

I'm currently focused on expanding my work in test automation, API testing, CI/CD and Quality Engineering.
